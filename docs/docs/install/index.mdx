# Install

HomeGallery is a command line tool to init the configuration, start the
web server at [localhost:3000](http://localhost:3000) and import the
media sources. To run your gallery at home you need to

<Steps>
    ### Install

    Choose your runtime

    ### Initialize

    Configure your media sources

    ### Run CLI

    Start the web server and import sources
</Steps>

HomeGallery can run through

- via [docker-compose](./docker-compose.md)
- as [docker container](./docker.md)
- [prebuilt binary](./binary.md) on Linux, Mac on Windows
- [application bundle](./app-bundle.md) on for Linux, Mac on Windows
- [generic application bundle](./generic-bundle.md)
- from [source](./source.md)
